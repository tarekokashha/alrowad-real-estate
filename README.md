# الرواد للتطوير العقاري — الموقع ولوحة التحكم

موقع عربي (RTL) لشركة وساطة عقارية في حدائق أكتوبر، الجيزة، ومعاه لوحة تحكم
كاملة بالعربي.

**الفكرة المركزية:** كل المنافسين بيقولوا «إحنا الأفضل». ولا واحد بيوريك الورق.
الموقع ده بينشر الحالة القانونية لكل وحدة، ومؤشر سعر متر مؤرَّخ بعيّنته، وسجل بيع
مفتوح — وده في نفس الوقت استراتيجية الثقة واستراتيجية الظهور في جوجل والـAI.

---

## التشغيل

```bash
npm install
cp .env.example .env      # واملأه
npm run seed              # يستورد الوحدات والصور والشهادات والمؤشر
npm run admin             # يعمل حساب المدير من بيانات .env
npm run dev               # الموقع :3100 · اللوحة :3100/admin
```

---

## الأوامر

| الأمر | بيعمل إيه |
|---|---|
| `npm run dev` | تشغيل التطوير على المنفذ 3100 |
| `npm run build` | بناء للإنتاج |
| `npm run seed` | استيراد المحتوى (مرة واحدة، آمن لو اتكرر) |
| `npm run admin` | إنشاء المدير أو تغيير كلمة المرور |
| `npm run typecheck` | فحص الأنواع |
| `npm run generate:types` | توليد أنواع Payload بعد تعديل الحقول |

## البنية

```
app/[locale]/          صفحات الموقع — ar و en
app/(payload)/         لوحة التحكم والـ API
collections/           تعريفات Payload (الوحدات، الصور، الطلبات…)
components/            مكوّنات الواجهة
lib/                   المحتوى والأدوات ونظام الحركة
scripts/               seed و admin
```

**ملاحظة مهمة:** صفحات الموقع بتقرأ من `lib/*.ts` مباشرة وبتتبني ستاتيك.
لوحة التحكم بتشتغل جنبها. لو حبيت الصفحات تقرأ من قاعدة البيانات، ده تعديل
منفصل — الموقع دلوقتي شغال من غير قاعدة بيانات خالص.

## القواعد المفروضة في الكود

مش نصايح — دي محطوطة في `collections/Units.ts` وبترفض الحفظ:

- **مفيش نشر من غير صورة حقيقية واحدة على الأقل.** كل صورة لازم تتصنّف
  «حقيقية» أو «تعبيرية»، والتعبيرية بيظهر عليها لابل للمشتري. ده أهم حارس في
  المشروع: المشتري المصري أصلاً بيفترض إن الصور مضروبة، ولو اتمسك إن صورة
  مولّدة معروضة على إنها الوحدة، الضرر أكبر من أي ترتيب في جوجل.
- **الحالة القانونية وتاريخ آخر مراجعة للسعر وتاريخ الزيارة إجباريين.**
- **الشهادة محتاجة اسم ومدينة ونوع وحدة وتاريخ** — «اسم أول + نجمة» شكله مضروب.
- **مفيش تحكم في الألوان ولا الخطوط** في اللوحة. التصميم محسوم.

## نظام التصميم

- **الألوان:** حجر جيري (`#F4F1EA`) وحبر دافي (`#1B1A17`) وبرونز (`#9A6B3F`).
  البرونز أقل من ٥٪ من أي شاشة وله تلات وظايف بس. **مش دهبي** — ولا كحلي.
- **الخطوط:** Amiri للعناوين (إحياء مطبعة بولاق)، IBM Plex Sans Arabic للنص.
  **ممنوع Cairo و Tajawal و Almarai** — دول اللي بيخلوا أي موقع مصري يبان قالب.
- **الحركة:** منحنيين، تلات مدد، تتابع واحد. في `lib/motion.ts`.

## قواعد العربي

- العربي أكبر ٥–١٥٪ وأوسع ١٥–٢٠٪ من اللاتيني — توكن بيتبدّل على `:lang(ar)`
- `letter-spacing: 0` على كل عنصر عربي، **من غير أي استثناء**
- الأسعار بأرقام إنجليزية، والأرقام العربية للإحصائيات داخل الجُمل بس
- كل سعر ورقم تليفون جوّه `<bdi>` — من غيرها بتتقلب
- خصائص CSS منطقية (`margin-inline`) مش `left/right`
